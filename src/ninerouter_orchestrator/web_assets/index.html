            Shared MCP servers
            Define a server once for Codex and OpenCode, then add a tool override only when one runtime needs different settings. All 9router combos use OpenCode's resolved connections.
            
      
            Scope: all repositoriesEach run saves an MCP snapshot. Later global edits do not change existing runs.
            
      
            A tool override with the same server name replaces the shared definition for that tool. Only add trusted servers: local commands can execute on this machine and remote tools may change external data. OAuth sign-in remains separate in each CLI.
