          How commands run

          Uses Bash on macOS and Linux or cmd.exe on Windows. Each run starts a fresh, non-interactive shell in the workspace folder. Keep servers in the foreground.

          Tabs and history persist across reloads; stopping Switchyard stops its commands. No timeout means run until finished or stopped.
